Direct npm packages and external Actions were already on their current majors after the merged Dependabot work. The PR advances their patch/minor releases and replaces floating major references with exact current releases. Transitive major differences are assessed against the upstream consumer API/range, recorded per occurrence in the CSVs, and forced only for existing specifically tested adapters/overrides. An override of every nested CommonJS dependency to an incompatible ESM/API major would not preserve the consumer's integration.

## Recorded exceptions and residual upstream work

The complete exception set is occurrence-level, not only a shortlist: see every CSV under `dependencies/`. Important cases are Python 3.14.10 versus latest 3.15.2; Java 21 versus 27; NumPy 2.4.6 versus 2.5.4 and preshed 3.0.13 versus 3.0.15 required by Presidio; srsly 2.5.6 and thinc 8.3.14 required by spaCy; textblob 0.15.3 required by scrubadub; and nested npm majors constrained by their current consumers. They are not unresolved security findings: all three npm graphs and the full Python lock are separately audited.

All retained workaround reports are listed in `upstream/reports.json`, with exact posted bodies beside them. Eleven reports/comments cover temp cleanup, artifact unzip deprecation, actionlint self-reference, actionlint queue schema, setup-node cache order, PyYAML cp315 wheels, Buildx registry failover, upload finalization retry/reconciliation, archiver-utils glob, Pages create retries, and Presidio's preshed cap. Existing upstream issue/PR discussions were checked before reporting. Assertions distinguish actual CI reproduction from mocked network fault injection; no simulated outage is presented as a live upstream outage.

No production feature was removed. Deleted logic consists of duplicated semver parsing, Windows shim generation, obsolete Corepack fallback and BuildKit pull retry/retag code now supplied by upstream. Existing artifact integrity/authentication, cleanup callbacks, registry fallback, release modes, cross-platform packaging and all three JS runtimes remain covered.
