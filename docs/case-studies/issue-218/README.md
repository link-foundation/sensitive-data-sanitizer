## Component choices

The existing whole-document restore implementation uses document hashes and raw
occurrences to preserve exact escaping. That behavior is useful for archived
documents. Live replies use canonical text for the literal token in its
authorized map. A trie keeps the incremental matcher independent of a large
alternation or provider vocabulary, and it needs only bounded carry instead
of replaying the whole reply on each delta. Gateway adapters can render the
same replacement in a different representation by serializing the complete
envelope after the edit.

For a full provider integration, [eventsource-parser](https://github.com/rexxars/eventsource-parser/blob/f46b5575f72682527ed936763983bdda0e1283f5/README.md)
can decode SSE fields incrementally and documents a buffer limit. The provider
adapter must still validate JSON payloads, demultiplex application deltas and
apply authorization. The repository example stays limited to data-only Chat
Completions SSE. LLM Shield Proxy's
[chunk-invariance](https://github.com/ninadphalak/LLM-Shield-Proxy/tree/ff5df7bdcce569498b7762a7edd72e59f9bfb343/chunk-invariance-js)
provides reusable test tooling. The focused fixtures here exhaust every single
cut and also stream bytes individually, without another runtime dependency.

[Microsoft Presidio](../../API.md#report-adapters) already supplies a useful
code-point report bridge. [OpenAI Privacy Filter's typed output](https://github.com/openai/privacy-filter/blob/f7f00ca7fb869683eb732c010299d901457f19c3/OUTPUT_SCHEMAS.md)
has its own label taxonomy and reports tokenizer round-trip mismatches.
[Ollama's compatibility interface](https://docs.ollama.com/api/openai-compatibility)
is one possible loopback target for JSON-mode Chat Completions. The endpoint
contract and synthetic HTTP fixtures decouple the tests from hardware, model
weights and the endpoint's hosting stack.
