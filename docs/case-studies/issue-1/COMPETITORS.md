# Competitor capabilities, integration and remaining work

Primary source review date: 2026-10-07. The capability/design matrix is supplemented by the finite, independently executed [review-corpus comparison](../../../experiments/benchmark/README.md); it is not a market ranking. A detector union can recover different engines' findings, but shared blind spots and false positives remain. Every selected engine must succeed, including final-output verification.

| [TruffleHog](https://github.com/trufflesecurity/trufflehog)                                                                                                                              | Provider detectors, decoders and optional credential verification; repository/filesystem sources  | Optional required filesystem detector, verification/updates disabled, private temp input; actual 3.99.0 run    | Benchmark supported decoders/false positives; online validity checks require explicit application policy                      |
| [detect-secrets](https://github.com/Yelp/detect-secrets)                                                                                                                                 | Plugin regex/entropy detection, hashed baselines and human audit                                  | Native credential vocabulary and quoted hex/base64 entropy; baseline adapter; independent pinned benchmark     | A live plugin bridge needs versioned fixtures, complete-report checks and residual invocation                                 |

| [scrubadub](https://scrubadub.readthedocs.io/en/stable/)                                                                                                                                 | Extensible PII detectors/postprocessors, localization, optional name/address dependencies         | Default multilingual name gazetteer, national phones/addresses and validators; independent scrubadub benchmark | Implement a bridge with locale-specific labeled fixtures; do not infer language coverage from installed package names         |
| [Betterleaks](https://github.com/betterleaks/betterleaks)                                                                                                                                | Gitleaks-related successor project with its own rules and scanning behavior                       | Researched current alternative; no claimed tested adapter compatibility                                        | Pin a release and validate its executable/report contract before substituting it                                              |
| [git-filter-repo](https://github.com/newren/git-filter-repo)                                                                                                                             | Reviewed rewriting of blobs, paths, messages and identity metadata                                | Clone-only preview/rewrite with private generated plans, actual tool test, and post-rewrite audit              | Rehearse against a disposable clone and immutable backup, verify refs/snapshots, then coordinate remote cleanup               |

Native entropy is a small supplemental Shannon-entropy heuristic, not a port of every competitor plugin. Report compatibility also differs from running a detector: the detect-secrets adapter can consume a caller-created baseline, while the default pipeline actually runs Secretlint. Known dictionaries and bounded normalization/decoding complement these components rather than establish model equivalence.

Closed documentation does not disclose every algorithm or model. Supporting report offsets is concrete interoperability; it is not a claim to reproduce all documented transformations, consoles, storage backends or model quality. The package does not upload text to a cloud service.

## Executed benchmark and remaining comparative work

Before claiming comparative superiority, freeze versions/configuration and define a publishable corpus with no real credentials: labelled positives and negatives by service, language, context, encoding and truncation. Include public/private ambiguities and benign code/counters. Record recall, precision, complete-span leakage, output syntax preservation, failure behavior, wall time and peak resident memory separately. Evaluate held-out examples and independent reviewers' labels; do not count one fixture per prefix as population recall.

Run each competitor independently and the union on the identical corpus. For proprietary models, use explicitly approved test accounts/data and record the selected regions/models/API versions. Report uncertainty and unsupported features rather than substituting marketing service counts for measured quality. The committed benchmark independently runs the default package, Gitleaks 8.30.1, TruffleHog 3.99.0, detect-secrets 1.5.0, Presidio 2.2.364 and scrubadub 2.0.1 on 223 synthetic cases/210 spans. The package covers all 210 complete spans with no false predictions on this development corpus. Per-engine settings, scope bias, overlap-precision definition, raw range predictions and source/corpus hashes accompany the results. This does not establish held-out or market-wide superiority.
