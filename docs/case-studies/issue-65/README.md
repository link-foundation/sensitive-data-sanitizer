## Research and alternatives

- [Presidio anonymizer](https://microsoft.github.io/presidio/anonymizer/) provides extensible operators and overlap handling. Existing repository adapters already allow Presidio; adding a Python service for these deterministic matching fixes would add deployment requirements.
- [pymorphy3](https://github.com/no-plagiarism/pymorphy3) offers Russian/Ukrainian morphological analysis with dictionaries. It is an option for a caller-side detector; the chosen core approach uses bounded, explicit ending alternatives anchored to caller-confirmed entities, avoiding Python/dictionary downloads and broad stemming of unknown prose.
- [Faker localization](https://fakerjs.dev/guide/localization) and [person API](https://fakerjs.dev/api/person) already provide locale/gender-specific first, last and middle names. Reuse this installed dependency and fix role inference rather than add another generator.
- [GeoNames download data](https://download.geonames.org/export/dump/) offers cities15000 with attribution/licensing obligations. A finite authored expansion and contextual unknown-city rules cover this issue without importing a worldwide dataset. Vocabulary remains deliberately bounded and offline.

Implementation order: shared known-value boundaries/morphology and selection; placeholder namespace and identity linking; document entities; credential prose and irreversibility reporting; fake roles; regression tests/docs/release fragment; focused local validation and full CI review. Existing debug callbacks remain off by default and provide value-free detection/residual events for tracing.

The morphology rules are finite alternatives for explicitly known or confirmed identities, not a general Russian parser. The document vocabulary is offline and bounded; ambiguous unlabelled prose still requires caller-provided known values. These limits preserve the existing conservative detection model while covering every reported example.
