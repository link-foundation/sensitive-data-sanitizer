## Research and existing components

- [ICAO Doc 9303 Part 3](https://www.icao.int/sites/default/files/publications/DocSeries/9303_p3_cons_en.pdf)
  defines MRZ character mapping and weighted check digits. Parts 4–7 define
  the document layouts. Detection must tolerate corruption independently of
  validation; a strict parser cannot decide whether damaged personal data is safe.
- [cheminfo/mrz](https://github.com/cheminfo/mrz) parses standardized MRZ
  documents. It is useful for generating/verifying exact layout fixtures but
  native tolerant matching is required for standalone/truncated log fragments.
- [Microsoft Presidio recognizers](https://github.com/microsoft/presidio/tree/main/presidio-analyzer/presidio_analyzer/predefined_recognizers/country_specific)
  provide confidence/context patterns and checksum reference implementations.
  The existing optional bridge already supports external model-based detection;
  native recognizers keep this package offline and usable without Python.
- [Nosey Parker rules](https://github.com/praetorian-inc/noseyparker/tree/main/crates/noseyparker/data/default/builtin/rules)
  include netrc and NuGet patterns. Research snapshots are retained locally;
  implementation uses format specifications rather than importing a new scanner.
- [PuTTY PPK format](https://www.puttyssh.org/0.80/htmldoc/AppendixC.html)
  documents version 3 headers, private payload and MAC boundaries, supporting
  complete-block redaction independently of the vendored v2 rule.
- [libphonenumber-js](https://github.com/catamphetamine/libphonenumber-js)
  provides phone search and region validation. Its metadata is useful for broad
  telephony support; the requested four contextual national shapes can be added
  without a new dependency or region guessing across all prose.
- [NHS number guidance](https://service-manual.nhs.uk/design-system/patterns/ask-for-nhs-numbers),
  [python-stdnum INN](https://github.com/arthurdejong/python-stdnum/blob/master/stdnum/ru/inn.py)
  and [Envek/snils](https://github.com/Envek/snils) provide public validation
  references. These Python/Ruby components can validate canonical numbers, but
  do not locate contextual spans in JavaScript logs. Native arithmetic checks
  complement the format detectors; checksum validity does not prove issuance.
- Existing [Gitleaks](https://github.com/gitleaks/gitleaks) and
  [Secretlint](https://github.com/secretlint/secretlint) integrations remain
  enabled and provide union credential coverage. New exemptions are restricted
  to personal identity findings, never credentials from any engine.

Research accessed 2026-10-08. Source code and standards are the primary references;
no live credential verification or publication of real personal data is needed.
