# Stable finding rule identifiers

Use keys from the exported frozen `builtInRules` list in `rules: {id: false}`.
Unknown ids fail with ERR_CONFIG. Credential and mixed encoded/scanner rules
require `allowCredentialDisable: true`. A disabled rule does not suppress
another rule's overlapping finding. Rules gate automatic built-in findings;
explicit findings and custom callbacks retain caller policy. See [API](API.md#rule-type-and-field-policy).

Regenerate with `node experiments/issue-118/generate-rule-catalog.mjs`.
